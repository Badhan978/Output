システム全体のデータフロー

4つの領域(貴社オフィス / Cloudflare / Googleスプレッドシート / 外部サービス)を、番号付きの矢印がリクエストから投稿・実績回収まで一周します。

フローの説明

1担当者がPagesの画面から生成リクエスト → Workers → シートに登録
2Mac miniのAIエージェントがシートのリクエストを読取 → Fal AIで画像生成 → スライド動画を組立
3生成物をR2へ保存、ステータス+URLをシートへ書込
4検品画面(Pages)がWorkers経由でシートの状態+R2のプレビューを表示 → Go/FB(FBは②に戻り再生成)
5ADBマシンが承認済みキューをシートから読取 → R2から動画取得 → 実機がTikTokへ自動投稿
6投稿実績(再生数など)をシートの実績タブへ回収 → 画面で閲覧
認証情報は貴社発行・貴社管理です(Fal AIキー / Googleアカウント / Cloudflareアカウント)。ソースコード・マニュアル込みで納品します。
