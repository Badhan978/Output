Runway GWM-1 Deep Dive — 仕組みと競合

動画生成の会社Runwayが、ロボットの訓練・評価インフラ (world model) をどう実現し、誰と戦っているか。 技術の種明かしは「巨大動画モデルの物理知識を土台に、生成方式を作り替え、ロボットデータで仕上げて実機で検証」の3段構え。 競合は切り口の異なるUSPで同じ層に並び、価格と顧客名はまだほとんど公開されていない。

実現の仕組み — 3段構え

物理エンジンを書く代わりに、動画データから物理を「学習」で獲得する路線。CTO発言:「優れた世界モデルの前提はまず優れた動画モデル。ピクセルを直接予測するのが汎用シミュレーションへの最善手」。
① 土台 = Gen-4.5 の事前学習 大量動画から物体の動き・光・接触など「世界の物理」をピクセル予測として獲得済み
→
② 生成方式の転換 一発生成をやめ「過去フレーム+制御入力 → 次の1フレーム」の自己回帰型へ再構成。カメラポーズ・Robot Pose・イベントを毎フレーム注入可
→
③ ドメイン仕上げ + 実機検証 roboticsデータでpost-training (中身は非公開)。実機8ポリシーの結果と突き合わせて相関0.95を実証

提供製品 4つ — Python SDK・申請制

コンシューマー向けではなく、ロボティクス企業向けインフラ。価格は非公開・商談ベースのみ。

Policy Model

カメラ観測からアクションを予測する制御モデル。顧客のハードウェア・環境ごとにファインチューン

Video Model Licensing

GWM-1をバックボーンとして貸与。顧客インフラ内で自社ポリシーを訓練 (データを外に出さない)

Offline Policy Evaluation

実機デプロイ前に仮想世界内でポリシーを走らせ失敗モードを検出。開発イテレーションを高速化

Data Augmentation

実軌跡データを別環境・照明・物体配置に変換し、訓練分布を実データ収集なしで拡張

価格の現在地

公開しているのはWorld LabsとDecartの従量制2社のみ。RunwayとGeneral Intuitionは価値ベースのエンタープライズ商談を探る段階で、市場はまだ「価格発見」の途中。

顧客の現在地

ロボティクス用途で顧客ロゴを出せているのは実質NVIDIAだけ。Runwayが顧客名を出せないのは出遅れではなく、市場全体の現在地。

最大の変数

中国OSSの無料攻勢が価格の天井を規定しにいく。Google Genie 3のB2B参入、Decart買収 (報道) の成立も地図を変え得る。

L4 データ供給 — 誰に何を売っているか

純粋な「データ販売」は上4社。Rerun/Foxgloveはデータを扱う道具を売るツール企業 (顧客名を公表できているのはツール側だけ)。データ4社の売り物はすべて実世界データ (人間の実演・teleop軌跡) — 合成データ専業はこの層に不在で、合成はL3のモデル勢が担う構図。

買い手はモデルを作る側

実名確定の大口はGoogle DeepMind (Apptronik「Robot Park」から供給)。XDOF/Micro1の顧客も「フロンティアラボ」— データに払うのはモデル開発勢に限られる。

最有力の買い手ほど自製

Physical Intelligence・1X・Tesla・Figureは収集を垂直統合し外部購入の形跡なし。日本の安川・FANUC (NVIDIAツールで自製) と同じ構造。

売り手の共通点

食い込めているXDOF・Micro1・Apptronikは「ラボが自前で組織できない物量の人的オペレーション」の肩代わり。データ販売の実体はオペレーション業。

L3は国策が占有

基盤モデル本体はNoetra×産総研「FRONTia」(44社連合・5年約1兆円)、データ基盤はAIRoA (205億円) が国費で着手済み。後発が正面から重なる意味はない。

空白 = 専業FDE

Cosmos Coalitionに日本大手21社が参加した一方、オープンworld modelを各社現場へfine-tune統合する専業は不在。最も近いアクセンチュア・classmethodも2025年末開始の立ち上げ期。

中間径路 = mimic型

フロンティアモデルは作らず、オープンweight (Cosmos等) を自社ドメインデータでpost-trainingし「派生モデル資産」を持つ型。スイスmimicが$3.25B評価の先行実例。
